
# BellaGestão

Sistema web para gerenciamento de agendamentos do Salão Distak.

## Sobre o projeto

O BellaGestão é uma aplicação desenvolvida para facilitar a organização dos atendimentos de um pequeno salão de beleza.

A solução busca substituir o controle manual de horários por uma agenda digital centralizada, permitindo o gerenciamento de clientes, profissionais, serviços e agendamentos.

## Objetivos

- Centralizar os dados dos clientes e profissionais.
- Gerenciar os serviços oferecidos pelo salão.
- Registrar e consultar agendamentos.
- Organizar a agenda por data e profissional.
- Evitar conflitos de horários para uma mesma profissional.

## Tecnologias previstas

- Python 3.12
- Flask 3.1
- SQLite
- SQLAlchemy
- Bootstrap 5.3
- Jinja2
- Flask-WTF
- Pytest

## Funcionalidades do MVP

1. Cadastro de clientes.
2. Cadastro de profissionais.
3. Cadastro de serviços e duração.
4. Registro e consulta de agendamentos.
5. Validação de disponibilidade e conflitos de horários.

## Arquitetura

O projeto utilizará uma arquitetura monolítica em camadas, organizada com base no padrão MVC (Model-View-Controller).

## Público-alvo

A aplicação será direcionada inicialmente à proprietária do Salão Distak, com foco na simplificação da rotina administrativa e na organização dos atendimentos.
